# Vitis Local Ancestry Inference HMM

This is a python-based pipeline for local ancestry inference (LAI) and chromosome painting using unphased amplicon-based genotyping data, developed for _Vitis spp._ hybrids.

The tool is a work in progress. Please let me know how it goes with your datasets and contact me with any questions or problems: ssv42@cornell.edu.

Manuscript in preparation: 
Genome-wide ancestry characterization and chromosome painting leveraging a large-scale
rhAmpSeq genotyping database establish a public resource for Vitis genetics and breeding.
Villwock S.S., Wilkerson D., Zou C., Heinitz C., Galarneau E., Worthington M.L., Cote L., Zhao D., Sheehan M., Cadle-Davidson L., and Sun Q. _In prep_ 2026.

Genotype data associated with the manuscript are in the `Vitis_public_data` directory:
- rhAmpSeq genotype data for _Vitis_ samples from the USDA germplasm repositories: hap_genotype_DVIT_GVIT_BI.gz
- Associated microhaplotype allele sequences: HaplotypeAllele.fasta.gz
- Clade-specific allele frequencies: refsetv6.2_allele_freq_by_clade.csv
