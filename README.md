# LAI_HMM

This is a python-based pipeline for local ancestry inference (LAI) and chromosome painting using unphased amplicon-based genotyping data, developed for Vitis spp. hybrids.

The tool is a work in progress. Please let me know how it goes with your datasets and contact me with any questions or problems: ssv42@cornell.edu.
